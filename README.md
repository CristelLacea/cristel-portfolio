## 🚀 Local Development

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start the Server**:
   ```bash
   npm start
   ```

3. **Open in Browser**:
   Visit [http://localhost:3000](http://localhost:3000)
